# 盛小天飞车 · 1024 程序员节特别版

一个用 three.js 做的 3D 卡丁车竞速小游戏，主角是盛小天。

在线试玩：https://1024.huangguanhao.com/

## 玩法
- 键位：↑ 加速，↓ 刹车，← → 转向，Shift 漂移，Ctrl / 空格 氮气，R 复位，C 视角，M 静音，P 暂停
- 漂移集气、出弯小喷 / 双喷、起步加速、加速带、`{ }` 代码块集气
- 3 张地图：极速海湾、冰雪山道、代码之城
- 6 种天气：晴天、黄昏、夜晚、雨天、雪天、大雾（雨雪天路面更滑）
- 个人赛 / 组队人机赛，3 档 AI 难度，4 种涂装

## 文件
- `index.html` 游戏本体
- `shengxiaotian.json` 盛小天 3D 模型（glTF）
- `img/` 盛小天表情贴纸
